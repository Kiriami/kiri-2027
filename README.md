# KIRI 2027 — FULL ASSISTANT

Русскоязычная PWA-система личного управления жизнью: цели, план дня, японский, тело, финансы, документы, образование, жильё, дневник, прогресс и помощник KIRI.

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

Для телефона приложение должно быть размещено по HTTPS. После открытия в Safari: **Поделиться → На экран Домой → Добавить**.

## Бесплатный запуск

Для статической версии можно использовать бесплатный хостинг статических сайтов, например GitHub Pages или Cloudflare Pages. Покупать домен не требуется.

## Данные

Основные данные хранятся локально в браузере через `localStorage`. API-ключи не находятся в клиентском JavaScript.

## Резервная копия

В разделе **Ещё → Резервная копия** можно скачать JSON и затем восстановить его на том же или другом устройстве.

## AI

Без ключа KIRI использует локальный rule-based помощник. Для внешней LLM предусмотрен backend-шаблон `backend/server.js` и `.env.example`.

Схема:

Клиент → ваш backend → AI API

Никогда не помещайте секретный API key в `app.js`.

## Важное

Юридические и миграционные вопросы не должны считаться подтверждёнными только по подсказкам KIRI. Для них нужно проверять актуальные официальные источники.
